# Unlisted newsletter articles

These articles have active direct-link pages but are not added to public feeds,
navigation, event cards or gallery albums. Both routes use noindex/nofollow
metadata. Anyone with the link can read them after deployment.

| Article | Section | Route |
| --- | --- | --- |
| Learning together, by Angel Nemakonde | Events | `/events/learning-together` |
| Watch Just Make It Work | Gallery | `/gallery/just-make-it-work` |

Content is in `unlisted.ts`. The shared `NewsletterArticle` component renders
paragraphs, headings, single photographs, paired photographs and action links.
Do not import this content into public listings until approved for listing.
